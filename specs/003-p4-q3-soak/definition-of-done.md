# Definition of Done — Soak

- [x] CLI runs a real DaySim without browser/UI dependency.
- [x] JSON reports only observed completed days, earnings, reputation, score and duration.
- [x] Errors are counted and returned nonzero; diagnostics are not hidden.
- [x] Ten real days complete with zero runtime crashes.
- [x] Two production-tuning runs match on gameplay fields.
- [x] Unit tests cover error paths and result shape.
- [ ] QA and Integrator review the proof and final branch diff.
